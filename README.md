# Portfolio — Svyat Korolyov

My personal portfolio as frontend developer. Single-page SPA with cursor-reactive Three.js grid mesh, floating particles, glitch typography, and Framer Motion animations.

## Tech

- **Next.js 16.2.7** (App Router)
- **TypeScript**
- **Three.js** — cursor-reactive deforming grid + particle field via custom GLSL shaders
- **Framer Motion** — staggered entrance animations + hover states
- **Tailwind CSS**
